# Subway Runner 3D

3D Endless Runner в стиле Subway Surfers на **React + React Three Fiber**.

## Играть онлайн

После первого деплоя игра будет доступна здесь:

**https://listok222.github.io/subway-runner-3d/**

## Управление (ПК)

- **A** или **←** — полоса влево
- **D** или **→** — полоса вправо
- **Пробел** / **W** / **↑** — прыжок

## Как запустить локально

```bash
git clone https://github.com/listok222/subway-runner-3d.git
cd subway-runner-3d
npm install
npm run dev
```

## Деплой на GitHub Pages

Всё уже настроено. При каждом пуше в `main` автоматически собирается и публикуется на GitHub Pages.

Если страница ещё не появилась:
1. Зайди в Settings репозитория → Pages
2. Source выбери **GitHub Actions**
3. Подожди 1–2 минуты после пуша

## Что уже есть

- Игрок бежит вперёд автоматически
- 3 полосы с плавным переключением
- Прыжок
