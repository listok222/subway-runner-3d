# Subway Runner 3D

3D Endless Runner в стиле Subway Surfers на **React + React Three Fiber**.

## Управление (ПК)

- **A** или **←** — переключиться на полосу влево
- **D** или **→** — переключиться на полосу вправо
- **Пробел** / **W** / **↑** — прыжок

## Как запустить

```bash
npm install
npm run dev
```

Открой http://localhost:5173 в браузере.

## Что уже есть

- Игрок бежит вперёд автоматически
- 3 полосы с плавным переключением
- Прыжок с гравитацией
- Камера следует за игроком
- Простая бесконечная трасса
- Счёт
- Экран Game Over + рестарт
