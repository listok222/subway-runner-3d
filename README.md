# Subway Runner 3D

Простая 3D endless-runner игра в стиле Subway Surfers.

## Играть

**https://listok222.github.io/subway-runner-3d/**

## Управление

- **A** / **←** — полоса влево
- **D** / **→** — полоса вправо
- **Пробел** / **W** / **↑** — прыжок

## Что есть

- Бег вперёд
- 3 полосы
- Прыжки
- Препятствия
- Счёт + Game Over
- Увеличение скорости

Сделано с помощью Grok.
